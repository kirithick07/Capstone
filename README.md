# Home Appliance Maintenance Management Platform

## Project Overview

A web-based application designed to efficiently manage home appliance maintenance, service requests, appointments, technicians, and service tracking.

## Technology Stack

* Java
* Spring Boot
* HTML
* CSS
* JavaScript
* MySQL

## Purpose

This project is developed as a **Semester 5 Capstone Project** to provide a digital platform for managing home appliance maintenance services efficiently.
